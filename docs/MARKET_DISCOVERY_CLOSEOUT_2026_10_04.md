## 快照保留

每次成功发布后尝试清理，没有新增 scheduler。清理与发布共用 `refresh.lock`；清理期间 `prune.lock` 阻止新读者进入待清理文件。

保留最近7天、至少最新2份、当前指针、仍被 Web manifest/quote 对象持有的快照，以及这些快照引用的全部历史快照。Web 写入进程保护标记，对象回收才释放；回收延迟或无法确认进程退出时保守保留。崩溃进程标记只在确认 `ESRCH` 后清理；PID 被复用可能延长保留。

清理前检查目录身份、链接、manifest 时间、当前指针、读者标记与保留集合的历史引用。损坏或缺失即中止；不抢占遗留锁。删除目标必须是 `data/market-runtime/snapshots/` 的直接子目录。维护失败不会把成功发布改成数据源失败，下一次发布或手动执行时再尝试。

```powershell
npm run market:prune             # 默认仅预览
npm run market:prune -- --apply   # 显式执行
```

committed `data/market/` 不参与清理。当前本地两份运行快照均被保留，预览候选为零；本次没有删除实际行情快照。
